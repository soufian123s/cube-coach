# Cube Coach 🧩

Application pédagogique autonome pour résoudre un Rubik’s Cube 3×3, avec scan photo, guidage pas à pas, animation et rapports.

## Publication via GitHub Pages

1. Créer un dépôt public `cube-coach` sur GitHub.
2. Importer **les fichiers contenus** dans ce dossier (`index.html`, `.nojekyll`, `README.md`) à la racine du dépôt, sur la branche `main`.
3. Dans **Settings → Pages → Build and deployment**, sélectionner **Deploy from a branch**, branche `main`, dossier `/(root)`, puis **Save**.
4. Ouvrir `https://VOTRE-IDENTIFIANT.github.io/cube-coach/`.

La caméra nécessite une autorisation du navigateur et un contexte sécurisé (HTTPS, fourni par GitHub Pages). La reconnaissance automatique des couleurs peut nécessiter des corrections manuelles.

L'application contient du code de bibliothèques tierces et leurs notices de licence dans le fichier HTML. Vérifiez-les avant redistribution.
